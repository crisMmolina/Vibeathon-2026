# estados.geojson

- 32 Mexican states (`cve_ent` INEGI key, `nombre`, `iso`), coordinates rounded to 4 decimals.
- Source: `mexicoHigh.json` from https://github.com/angelnmara/geojson (downloaded 2026-11-21). The repository declares **no license** → **[To validate license]**. Demo use with attribution only.
- `cve_ent` was added by mapping the ISO 3166-2 codes (`MX-JAL` → `14`).
- For a pilot: replace with the INEGI Marco Geoestadístico (free use with attribution), simplified with mapshaper under 500 KB.
